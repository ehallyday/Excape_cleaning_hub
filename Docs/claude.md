# Project

## Goal
High-converting landing page for a local cleaning business.

## Tech Spec
— Single index.html, embedded CSS, vanilla JS
— Tailwind CSS via CDN is allowed
— Mobile-first, fully responsive
— Target load time: under 2 seconds
...

## Design
Modern
Premium
Minimal
Large typography
...

## Sections (in this order):
1. Sticky nav — logo + phone (tel: link) + CTA
2. Hero — headline addresses the #1 audit pain
3. Trust bar — 3 signals (insured, rated, years)
4. Services — cards with descriptions + pricing
5. Reviews — real snippets from business.md
6. About — 2–3 short paragraphs
7. Contact form — name, phone, service, date
8. Footer — address, phone, hours, Maps embed

## Content Rules
- Mobile-first
- Use existing components where possible
- Don't change the tech stack
- Preserve the established visual language
- Prioritize conversion
— Use real business name, phone, address
— Hero headline must reference the audit pain
— Plain English throughout
— No lorem ipsum in final output


Deliver: a single index.html ready for Live Server.
